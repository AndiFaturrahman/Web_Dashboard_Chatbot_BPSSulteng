# BPS AI Dashboard

This is the web dashboard for the BPS AI project, built using [Streamlit](https://streamlit.io/).

## Setup Instructions

1. **Install dependencies:**
   It is recommended to use a virtual environment (e.g., `venv` or `conda`).
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the dashboard:**
   ```bash
   streamlit run app.py
   ```
