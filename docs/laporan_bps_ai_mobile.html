1. Ringkasan Eksekutif (Executive Summary)

Aplikasi BPS AI Assistant Mobile adalah inovasi diseminasi data statistik berbasis kecerdasan buatan (Artificial Intelligence) yang dirancang khusus untuk mempermudah masyarakat, akademisi, pimpinan instansi, dan pembuat kebijakan dalam mengakses, memahami, dan memanfaatkan data resmi Badan Pusat Statistik (BPS) secara instan, interaktif, dan akurat.

Berbeda dengan chatbot AI konvensional yang kerap mengalami hallucination (data fiktif atau usang), sistem ini menerapkan metode Retrieval-Augmented Generation (RAG) 2-Step Workflow yang terhubung secara real-time ke BPS Web API resmi (webapi.bps.go.id).

Pencapaian Utama Fase 1:
  • Backend Gateway telah aktif secara permanen di server cloud Vercel dengan latensi rendah.
  • Terkoneksi langsung ke server BPS Web API menggunakan API Key terotentikasi.
  • Aplikasi mobile Flutter telah berhasil dikompilasi menjadi berkas installer Release APK (app-release.apk) berizin internet penuh dan siap dipasang di HP Android pengguna.

2. Latar Belakang & Tujuan Strategis

2.1 Latar Belakang Masalah

  1. Kompleksitas Akses Data: Publik sering mengalami kesulitan menemukan data statistik spesifik di portal web yang memiliki ribuan tabel dan Berita Resmi Statistik (BRS).
  2. Kebutuhan Narasi Cepat: Pengguna memerlukan penjelasan naratif singkat yang mudah dimengerti mengenai makna indikator makro, bukan sekadar tabel angka mentah.
  3. Mitigasi Misinformasi: Menjamin bahwa seluruh rujukan angka yang diberikan kepada publik bersumber 100% dari rilis resmi BPS RI.

2.2 Tujuan Strategis Proyek

  • Meningkatkan Literasi Statistik: Menyediakan sarana konsultasi cerdas mengenai definisi indikator (seperti Inflasi, PDRB, IPM, Kemiskinan, NTP, TPT).
  • Otomatisasi Diseminasi: Menghubungkan masyarakat secara langsung ke dokumen rilis resmi (PDF BRS) hanya dalam 1 klik.
  • Mendukung Pengambilan Kebijakan (Data-Driven Policy): Memberikan akses data indikator makro secara cepat bagi pimpinan saat rapat maupun dinas lapangan.

3. Arsitektur Sistem & Spesifikasi Teknologi

Sistem dibangun dengan arsitektur modular yang memisahkan lapisan antarmuka pengguna (Frontend Mobile), lapisan pemrosesan & integrasi (FastAPI Gateway), model bahasa besar (Google Gemini AI), serta basis data resmi BPS.

Komponen Teknologi Peran & Fungsi
Frontend Mobile Flutter SDK 3.38.7 / Dart 3.10.7 Antarmuka obrolan responsif, tema resmi BPS, dan kartu UI terstruktur.
Backend Gateway FastAPI (Python 3.13) + Uvicorn Pengontrol logika RAG, parser intent, dan middleware CORS.
AI Engine Google Gemini 3.7 / 3.6 / 3.5 Flash Pemrosesan bahasa alami Indonesia, ekstraksi entitas, dan penyusunan narasi data.
Data Provider BPS Web API (webapi.bps.go.id) Sumber data statistik resmi (BRS, tabel statis, subjek, publikasi).
Cloud Hosting Vercel Serverless Edge Cloud Infrastruktur backend cloud aktif 24/7 dengan enkripsi HTTPS global.
Packaging Android Release APK (45.3 MB) Paket installer aplikasi mandiri dengan izin akses internet penuh.

Alur Data (RAG 2-Step Workflow)

1. User Input    ──> Pengguna mengetik: "Berapa inflasi Indonesia pada Juli 2026?"
2. Step 1 Extract ──> Gemini AI mengekstrak: intent="numeric", keyword="inflasi", domain="0000"
3. Step 2 Fetch   ──> Backend query ke BPS Web API (model=pressrelease, keyword=inflasi)
4. Live Data In  ──> Server BPS mengembalikan data BRS Juli 2026 (Inflasi: 2,88%, IHK: 111,73)
5. Step 3 Narate ──> Gemini AI menyusun narasi resmi + kartu data payload + sitasi dokumen PDF
6. Rendering UI  ──> Flutter menampilkan kartu data rapi + tombol unduh PDF resmi BPS

4. Fitur-Fitur yang Telah Selesai Diimplementasikan

1. Gateway Data Riil BPS Terintegrasi (Live RAG)

Menjawab pertanyaan indikator makro ekonomi, ketenagakerjaan, pertanian, sensus, dan kemiskinan dengan data aktual yang diambil langsung dari server BPS.

2. Kartu Statistik Terstruktur & Sitasi PDF Resmi

Menampilkan kartu ringkasan visual berisi nama indikator, angka capaian, wilayah, periode, serta tombol pembuka dokumen rilis resmi (PDF BRS).

3. Multi-Model Resilience (Anti-503 Error System)

Mekanisme failover otomatis berantai antar-model (Gemini 3.7 ➡️ 3.5 ➡️ 3.6 ➡️ Flash Latest) untuk memastikan ketersediaan layanan 100% tanpa gangguan server overloaded saat demo.

4. Desain UI/UX Standar Resmi BPS & Zero Overflow

Mengadopsi palet warna resmi BPS (BPS Blue #00ADEF, Orange #F7941D, Green #8CC63E) dengan antarmuka yang dioptimasi bebas garis kuning-hitam pada seluruh ukuran layar.

Untuk membawa aplikasi BPS AI Mobile menjadi Produk Unggulan Nasional (Flagship App BPS RI), berikut rekomendasi rencana pengembangan fase selanjutnya:

Fitur Deskripsi Pengembangan Dampak Strategis

🔔 Live BRS Feed Tab dashboard indikator makro dan feed rilis Berita Resmi Statistik harian dari server BPS. Menjadi portal pemantauan indikator strategis harian pimpinan.
